# Sitio Web Turístico de la Ciudad Ficticia: Aurora

Proyecto grupal desarrollado para la materia **Lenguajes Informáticos 1** (UNAHUR - Instituto de Tecnología e Ingeniería).

---

## 📌 Descripción del Proyecto

El proyecto consiste en el desarrollo progresivo de un sitio web de información y promoción turística sobre la ciudad ficticia de **Aurora**. El sitio permite a los visitantes conocer la historia, características, atractivos principales, propuesta cultural y medios de contacto de la ciudad.

El desarrollo se realiza de forma incremental a lo largo del cuatrimestre, aplicando buenas prácticas de maquetación web, control de versiones y trabajo colaborativo mediante Git y GitHub.

---

## 🚀 Etapas del Proyecto y Hoja de Ruta

- [x] **Etapa 1: Estructura HTML (Clase 5)** — Maquetación con HTML5 semántico completo, enlaces internos/externos, listas, tablas/datos clave y navegación accesible.
- [ ] **Etapa 2: Estilos CSS (Clase 8)** — Hoja de estilos externa (`estilos.css`), definición de layout, tipografías, colores y espaciado.
- [ ] **Etapa 3: Framework CSS (Clase 12)** — Integración de **Bootstrap**, diseño responsivo (mobile-first) y uso de componentes.
- [ ] **Etapa 4: JavaScript (Clase 15)** — Lógica de interacción dinámica y validaciones en el cliente.

## 👥 Integrantes y Distribución del Trabajo

> **Nota:** Para garantizar el cumplimiento de los requisitos de Git, cada integrante desarrolla y comitea de forma independiente las secciones asignadas desde su propia cuenta de GitHub.

| Integrante | Rol / Archivos Asignados | Tareas Principales |
| :--- | :--- | :--- |
| **[Nombre 1]** | `index.html` | Estructura de la página de inicio, presentación general y resumen de atractivos. |
| **[Nombre 2]** | `ciudad.html` | Historia, identidad, barrios/zonas, costumbres y lista `<dl>` de datos clave. |
| **[Nombre 3]** | `lugares.html` | Secciones de atractivos turísticos, actividades, mapa/ubicaciones y recomendaciones. |
| **[Nombre 4]** | `contacto.html` | Formularios, enlaces de contacto (`mailto:`, `tel:`), redes sociales y mapas. |
